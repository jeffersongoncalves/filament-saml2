# Changelog

All notable changes to `filament-saml2` will be documented in this file.

## 2.0.0 - 2026-10-07

First release of `filament-saml2` for **Filament v4**. Same features as `1.0.0` (Filament v3) and `3.0.0` (Filament v5): SAML 2.0 SSO for Filament panels powered by [`jeffersongoncalves/laravel-saml2`](https://github.com/jeffersongoncalves/laravel-saml2), one login button per IdP tenant, RelayState-based panel resolution, NameID/e-mail/auto-create user resolution, polymorphic `saml2_identities` table, per-panel options, translations `en`/`pt_BR`/`es`.

```bash
composer require jeffersongoncalves/filament-saml2:"^2.0"

```
